Installer ColdBox

Supervision de chambres froides, installée chez vous : une commande sur un serveur Linux neuf.

Version 0.1. Première version de l'installateur. Installez-la d'abord sur une machine de test. Le code est privé : l'installation exige une clé personnelle fournie par l'éditeur.

1. Ce qu'il faut

  • Une machine Linux dédiée : Debian 12/13 ou Ubuntu 22.04/24.04, 2 Go de mémoire, 8 Go de disque libre, accès à Internet. Le pare-feu de la machine sera réglé par l'installateur (ports 22, 80, 443 et 8883).
  • Une adresse fixe pour ce serveur, joignable par les navigateurs et par les boîtiers : un nom de domaine (ex. froid.entreprise.dz) ou une adresse IP locale (ex. 192.168.1.50).
  • Une clé d'installation (commence par github_pat_), fournie par l'éditeur.

3. Pendant l'installation

    
Comptez plusieurs minutes (téléchargements et préparation). À la fin, l'installateur affiche l'adresse du site, l'e-mail de l'administrateur et son mot de passe, une seule fois. Notez-le, puis changez le mot de passe à la première connexion.

    
Avec une adresse IP et le mode auto-signé, le navigateur affichera un avertissement de certificat : c'est normal tant que le certificat n'est pas installé comme certificat de confiance.

  


  

    
4. Ensuite : la commande coldbox

    

      
coldbox statusÉtat des services, certificats, disque, dernière sauvegarde.

      
coldbox backupSauvegarde complète sans arrêt (faite aussi chaque nuit à 02:30, 14 conservées).

      
coldbox restore <fichier>Restauration d'une sauvegarde (avec copie de sécurité préalable).

      
coldbox renew-certsRenouvelle le certificat du broker MQTT (les boîtiers restent valides).

      
coldbox update <archive>Met à jour ColdBox en conservant les données.

    

    
Important : copiez régulièrement les sauvegardes (dossier /opt/coldbox/backups) hors du serveur. Elles contiennent l'autorité de certification des boîtiers : sans elle, les boîtiers déjà activés ne pourraient plus se connecter après une réinstallation.
