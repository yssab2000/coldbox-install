Installer ColdBox

Supervision de chambres froides, installée chez vous : une commande sur un serveur Linux neuf.

Version 0.1. Première version de l'installateur. Installez-la d'abord sur une machine de test. Cette page est un outil de l'éditeur : la commande générée contient la clé d'accès au code (lecture seule). Transmettez-la au client par un canal privé : il n'a rien d'autre à saisir.

1. Ce qu'il faut

  • Une machine Linux dédiée : Debian 12/13 ou Ubuntu 22.04/24.04, 2 Go de mémoire, 8 Go de disque libre, accès à Internet. Le pare-feu de la machine sera réglé par l'installateur (ports 22, 80, 443 et 8883).
  • Une adresse fixe pour ce serveur, joignable par les navigateurs et par les boîtiers : un nom de domaine (ex. froid.entreprise.dz) ou une adresse IP locale (ex. 192.168.1.50).

2. Préparer la commande

Les informations restent dans votre navigateur : rien n'est envoyé nulle part.

Sans « http:// » ni « / ».
Automatique : Let's Encrypt pour un nom de domaine, auto-signé pour une adresse IP.
Jeton GitHub en lecture seule sur le dépôt coldbox-saas.

Donnez cette commande au client (elle contient la clé : canal privé). Sur sa machine neuve, connecté en SSH, il la colle telle quelle :

3. Pendant l'installation

    
Comptez plusieurs minutes (téléchargements et préparation). À la fin, l'installateur affiche l'adresse du site, l'e-mail de l'administrateur et son mot de passe, une seule fois. Notez-le, puis changez le mot de passe à la première connexion.

    
Avec une adresse IP et le mode auto-signé, le navigateur affichera un avertissement de certificat : c'est normal tant que le certificat n'est pas installé comme certificat de confiance.

  


  

    
4. Ensuite : la commande coldbox

    

      
coldbox statusÉtat des services, certificats, disque, dernière sauvegarde.

      
coldbox backupSauvegarde complète sans arrêt (faite aussi chaque nuit à 02:30, 14 conservées).

      
coldbox restore <fichier>Restauration d'une sauvegarde (avec copie de sécurité préalable).

      
coldbox renew-certsRenouvelle le certificat du broker MQTT (les boîtiers restent valides).

      
coldbox updateMet à jour ColdBox vers la dernière version publiée, en conservant les données (détail ci-dessous).

      
coldbox set-keyEnregistre une nouvelle clé d'accès si l'ancienne a expiré (rarement utile).

    

    
Important : copiez régulièrement les sauvegardes (dossier /opt/coldbox/backups) hors du serveur. Elles contiennent l'autorité de certification des boîtiers : sans elle, les boîtiers déjà activés ne pourraient plus se connecter après une réinstallation.

  


  

    
5. Mettre à jour ColdBox

    
Les mises à jour ne s'appliquent jamais toutes seules : chaque installation reste sur la version reçue tant qu'on ne lance pas la commande. Les données, les clés, les certificats et la configuration sont conservés, et une sauvegarde est faite avant tout remplacement.

    
Mettre à jour (sur le serveur, connecté en SSH) :

    
sudo coldbox update

    
Aucune clé à saisir : elle a été enregistrée à l'installation. La commande affiche la version installée et la version disponible, télécharge la nouvelle version, vérifie son empreinte, sauvegarde, remplace le code et relance les services (quelques minutes).

    
Savoir s'il existe une nouvelle version, sans rien modifier :

    
sudo coldbox update --check

    
Choisir une version précise, par exemple pour revenir en arrière :

    
sudo coldbox update --version v0.1.2

    
Si la clé d'accès a expiré, la commande le dit et en demande une nouvelle, fournie par l'éditeur ; elle est enregistrée pour les fois suivantes.
